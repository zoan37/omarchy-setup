# Cyberspace: custom space/cyberpunk theme

A custom Omarchy theme — deep space-navy backgrounds, neon cyan accent
(`#00e5ff`), hot magenta (`#ff4fd8`), with NASA/ESA/ESO space photography plus
one procedurally generated synthwave wallpaper. Built August 2026 on the XPS 13.

Theme files and all wallpapers live in [`assets/cyberspace-theme/`](assets/cyberspace-theme/).

## Install

```bash
# Theme (colors, neovim/vscode themes, lock screen, keyboard RGB, first 5 wallpapers)
cp -r assets/cyberspace-theme/theme ~/.config/omarchy/themes/cyberspace

# Extra wallpapers — this folder is read live by the background switcher,
# no theme re-apply needed when adding more later
mkdir -p ~/.config/omarchy/backgrounds/cyberspace
cp assets/cyberspace-theme/user-backgrounds/*.jpg ~/.config/omarchy/backgrounds/cyberspace/

omarchy theme set cyberspace
# Default wallpaper (0- prefix sorts it first in the theme, but the combined
# background list sorts the user-backgrounds folder ahead of the theme's, so
# pin it explicitly):
omarchy theme bg set ~/.config/omarchy/themes/cyberspace/backgrounds/0-veil-nebula.jpg
omarchy theme bg cache   # thumbnails for the switcher (Super+Ctrl+Space)
```

All wallpapers are pre-cropped/downscaled to ~3200x2000 for the XPS 13's
2560x1600 panel. Fine on the SER8's 3440x1440 too (hyprpaper cover-crops), but
for a pixel-perfect ultrawide set, re-crop from the source links below.

## Details worth remembering

- **Muted active border**: `colors.toml` sets
  `hyprland_active_border = "rgba(4ff2f866)"` — the hyprland template reads
  this optional key before falling back to `accent`, so the window border is a
  40%-opacity cyan while the bar/terminal keep the full-neon accent. Last two
  hex digits are the opacity knob.
- **Backgrounds added to the theme dir after `theme set` don't show up** in the
  switcher until the theme is re-applied — the switcher reads the snapshot in
  `~/.local/state/omarchy/current/theme/`, not the theme dir. The
  `~/.config/omarchy/backgrounds/cyberspace/` folder has no such problem
  (read live), which is why the extra wallpapers live there.
- `3-neon-grid.jpg` is generated by
  [`assets/cyberspace-theme/synthwave.py`](assets/cyberspace-theme/synthwave.py)
  (pure-python SVG → `rsvg-convert` → jpg). Edit the palette constants in the
  script to re-render in a different colorway.
- Neovim uses cyberdream, VS Code uses SynthWave '84; both auto-install via the
  theme's `neovim.lua` / `vscode.json`.
